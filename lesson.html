How to find empty files and empty folders on your computer

Short answer

Folders pick up leftovers over time: files that hold nothing and folders with nothing in them. This lesson builds a small read-only Python tool that lists both inside a folder you pick, with paths relative to that folder. An empty file holds nothing (0 bytes). An empty folder holds no files anywhere inside it, so a folder that only holds other empty folders is listed too. The tool has no code that changes, moves or deletes anything, and it never opens the files.

Follow along and build it step by step. You add each file yourself, run each command, and see the real recorded result.

Common mistakes

  1. Thinking empty means useless. An empty file can be a placeholder a program expects, and an empty folder can be waiting for the next export. The tool lists what is empty; deciding is yours.
  2. Expecting a folder of empty folders to look full. A folder that only holds other empty folders still holds no files, so the tool lists it together with the folders inside it.
  3. Assuming the report saw everything. Entries the tool cannot read are skipped. The report only covers what it could see.

Frequently asked questions

What counts as an empty file?

A file that holds nothing: its size is 0 bytes. The tool asks the system for each file's size and never opens the file.

What counts as an empty folder?

A folder that holds no files anywhere inside it. A folder that only holds other empty folders is listed too, along with those folders.

Will this change or delete anything?

The checker reads only. The separate setup creates a new fictional sample and refuses an existing sample path. Tests check selected fixture bytes and metadata, not every real-world case.

Why do the paths not start with a drive letter?

Paths are printed relative to the folder you check, with forward slashes, so the same report reads the same on Windows, Mac and Linux.

Is an empty file safe to delete?

Maybe, maybe not. Some programs expect an empty placeholder file. The tool only reports what is empty; it never deletes, and the decision is yours.
